==========================================
     🏹 ЛУЧНИК — инструкция
==========================================

ФАЙЛЫ
-----
  Сайт игры: https://3forwork11235.github.io/luchnik/

  index.html         — сама игра
  room.js            — правила онлайн-комнаты (работают в браузере создателя игры)
  sw.js, manifest.webmanifest, icons\ — чтобы игру можно было «установить»
                       на телефон как приложение (PWA)
  server.py          — запасной сервер для игры по Wi-Fi без интернета: отдаёт
                       игру браузерам и пересылает сообщения между игроками
  start_server.bat   — запуск сервера (игра по Wi-Fi)
  start_online.bat   — игра через интернет (Tuna)
  open_firewall.bat  — один раз открыть порт 8765, если телефоны не подключаются
  requirements.txt   — зависимость Python (websockets)
  backup_old\        — старые версии, можно удалить


1. ИГРА НА ОДНОМ УСТРОЙСТВЕ (без сервера)
-----------------------------------------
Открой игру → «Игроки по очереди», «Против ИИ» или «Вместе против волн ИИ».


2. ОНЛАЙН НАПРЯМУЮ (P2P) — без сервера и без компьютера
-------------------------------------------------------
Сервером становится браузер того, кто создаёт игру. Остальные
подключаются к нему напрямую (WebRTC).
1. В меню «Онлайн» выбери «Напрямую (P2P)» → «Создать игру».
2. Отправь друзьям ссылку (вида …/#p2p=ABC123) или 6-значный код.
3. Нужен интернет: через бесплатный сервер PeerJS устройства находят
   друг друга. Дальше ходы идут напрямую, а в одной Wi-Fi сети
   (или на раздаче с телефона) — внутри неё.
4. Создателю игры лучше не сворачивать браузер: пока он свёрнут,
   ходы не проходят. Если вкладку перезагрузили, игра восстановится,
   а гости переподключатся сами. Если создатель вышел в меню, игра
   закрывается.

Чтобы ссылкой можно было пользоваться откуда угодно, папку с игрой
(index.html, room.js, sw.js, manifest.webmanifest, icons\) нужно
выложить на любой бесплатный хостинг с HTTPS: GitHub Pages,
Cloudflare Pages, Netlify. Тогда игроки просто открывают сайт,
а на телефоне можно нажать «Установить» / «На экран Домой».


3. ИГРА ПО WI-FI ЧЕРЕЗ СЕРВЕР НА НОУТБУКЕ (запасной вариант, работает без интернета)
-------------------------------------------------------------------------------------
В меню «Онлайн» выбери «Через сервер на компьютере». Если игра открыта
с адреса, который показывает server.py, этот способ выбран сам.
Правила игры и тут работают в браузере создателя игры (как в P2P),
а server.py только пересылает сообщения. Поэтому создателю игры тоже
лучше не сворачивать браузер.
1. На ноутбуке запусти start_server.bat.
   В окне появятся адреса, например:  http://192.168.1.5:8765
2. Все устройства должны быть в той же Wi-Fi сети, что и ноутбук.
3. На каждом телефоне (Android или iPhone) открой этот адрес в браузере
   (Chrome, Safari и т.д.). Ничего устанавливать не нужно.
4. Первый игрок нажимает «Создать игру» — появится ID и ссылка.
   Второй игрок открывает ссылку (или вводит ID и нажимает «Войти»).

Если телефон не открывает адрес:
   - запусти open_firewall.bat (попросит права администратора) — он
     разрешает входящие подключения на порт 8765 в брандмауэре Windows;
   - проверь, что телефон не в мобильном интернете, а в той же Wi-Fi;
   - в гостевых Wi-Fi сетях устройства часто не видят друг друга.


4. ЧЕРЕЗ ИНТЕРНЕТ С СЕРВЕРОМ НА НОУТБУКЕ (Tuna) — если P2P не соединяется
-----------------------------
1. Запусти туннель:  tuna http 8765   (окно не закрывать)
2. Запусти start_online.bat — он запустит сервер и покажет адрес
   вида https://xxxx.tuna.am
3. Оба игрока открывают этот адрес в браузере. Если Tuna покажет
   страницу-предупреждение — нажать «Посетить», откроется игра.
4. Дальше как в пункте 2: «Создать игру» → отправить ссылку другу.


КОМАНДЫ 2 НА 2 И БОТЫ
---------------------
- В меню выбери «Формат: 2 на 2» перед «Создать игру». Ссылку можно
  отправить трём друзьям — каждый займёт свободное место.
- Создатель игры может нажать «Начать», не дожидаясь всех: если включено
  «боты вместо недостающих», пустые места займут боты.
- Если игрок свернул браузер дольше ~8 секунд, за него ходит бот;
  вернулся — управление снова у него. Новый игрок может по ссылке занять
  место бота прямо во время игры.
- Деревья настраиваются в меню (нет / мало / много).


ЛУЧНИК 2.0 — ЧТО НОВОГО
-----------------------
- Меню с вкладками поверх живой партии ботов; Esc или ⏸ — пауза
  (на одном устройстве время останавливается, выход переспрашивает).
- Время суток раунда: рассвет, день, закат, ночь (звёзды, луна, светлячки).
  Выбирается по раунду — в онлайне у всех одинаково; можно закрепить
  в «Настройках».
- Кинокамера следует за стрелой, при хедшоте/добивании — наезд в
  замедлении (выключается в настройках или в паузе).
- Стоп-кадр и ударная волна при попадании, шлейф стрелы, лучи солнца,
  полосы ветра, трава на переднем плане, живые лучники (дыхание, плащ).
- Звук: музыка (лютня), река, ветер, птицы днём и сверчки ночью,
  скрип тетивы. Отдельная громкость музыки, эффектов и природы.
- «Призрак» прошлого выстрела — пунктир, по нему удобно поправлять прицел.
- Серии попаданий, объявления «Хедшот!», «Двойное попадание!»,
  награды на экране итогов (снайпер, урон, серия, охотник…).
- Новый режим «Тир»: 10 стрел по мишеням на трёх дистанциях
  (×1, качающаяся ×1,5, ×2) и воздушные шары; рекорд и две новые награды.
- Подсказки новичку при первых выстрелах; качество графики «Экономное»
  для слабых телефонов.


ЧТО ЕСТЬ В ИГРЕ (всё включается и выключается в меню)
------------------------------------------------------
- Ранения: в ноги — на следующий ход меньше шагов, в корпус/голову —
  дрожат руки.
- Особые стрелы (запас на раунд): огненная, тяжёлая, тройная.
- Ящики с бонусами на парашюте, камни и кусты, погода на раунд.
- Деревья можно срубить или сжечь; из пня через 5 ходов растёт новое.
- Время на ход (20/30/45 секунд), матч до 3 или 5 побед со статистикой.
- Вместе против волн ИИ — на одном устройстве или онлайн (выбери режим
  «Вместе против волн ИИ» перед «Создать игру»).
- Достижения открывают шапки и оперение стрел (хранятся на устройстве).
- Онлайн: быстрые фразы (💬), вибрация на телефоне при попадании.


ТЕЛЕФОНЫ И ПЛАНШЕТЫ
-------------------
- Поле само подстраивается под экран. Удобнее держать телефон
  горизонтально.
- Кнопка ⛶ включает полноэкранный режим (Android, ПК, iPad).
  На iPhone для полного экрана: Safari → «Поделиться» →
  «На экран „Домой“», и запускать игру с иконки.
- Управление: ◀ ▶ — шаги, выстрел — зажать палец на поле и тянуть
  назад; чтобы отменить, верни палец к точке нажатия.


ТРЕБОВАНИЯ
----------
- Любой современный браузер на устройствах игроков
- Для P2P: интернет
- Для запасного сервера: Python 3.8+ на компьютере
  (start_server.bat сам поставит websockets)

ДЛЯ РАЗРАБОТКИ
--------------
Правила комнаты (очерёдность, здоровье, деревья, запас стрел, бонусы,
волны) — только в room.js. server.py правил не знает, он только
пересылает сообщения, поэтому менять его при новых правилах не нужно.
Версия до всех дополнений помечена в git тегом v1.0.
