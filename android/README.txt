Лучник для Android (APK)
========================

Что это: обёртка над игрой из этой папки (index.html + room.js). Файлы игры лежат внутри APK,
поэтому игра против ИИ и вдвоём на одном телефоне работает и без интернета. Для онлайна нужен интернет —
приложение и сайт https://3forwork11235.github.io/luchnik/ играют друг с другом по одному и тому же ID игры.
Кнопка «Копировать ссылку» в приложении даёт ссылку на сайт — друг может открыть её в любом браузере.

Установка на телефон:
  1. Перекинуть luchnik-<версия>.apk на телефон (Telegram, кабель, Google Диск…).
  2. Открыть файл, разрешить «установку из неизвестных источников» для этого приложения.
  3. Google Play Защита может предупредить о неизвестном разработчике — «Всё равно установить».
  Android 7.0 и новее.

Пересобрать после изменений игры: запустить build_apk.bat.
  Версия APK берётся из const APP_VER в index.html — поднимите её, чтобы обновление ставилось поверх старого.
  Инструменты сборки (JDK 17 + Android SDK) лежат в C:\Users\danil\android-build.
  luchnik-release.keystore — ключ подписи. НЕ удаляйте: без него новую версию нельзя будет поставить
  поверх старой (только удалив приложение вместе с прогрессом).
